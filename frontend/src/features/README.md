# 工作台功能

| 目录 | 内容 |
| --- | --- |
| `workspace/` | 数据源配置、初始化、范围选择、工作区时间约定 |
| `catalog/` | 结构树、字段说明、采集覆盖状态、结构变化展示 |
| `exploration/` | SQL 探索、查询步骤、参数来源与临时结果 |
| `chain/` | 链路检索、草稿、版本确认、参数与步骤编辑 |
| `runs/` | 执行进度、取消、结果分页、历史与重跑 |

组件、composable、展示类型和测试优先与功能放在一起，有文件时再拆子目录。跨功能页面由 `app/` 组装，允许明确的单向组件复用，避免功能间循环依赖。通用展示提取到 `components/`，桌面通信集中到 `lib/ipc/`。

这些目录当前只有职责说明，没有页面、状态管理或业务实现。
